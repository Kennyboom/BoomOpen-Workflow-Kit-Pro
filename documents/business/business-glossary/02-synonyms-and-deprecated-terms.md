## Deprecated Terms (Do Not Use in `v5.5.0`)

Replace all legacy terms below with their canonical `v5.5.0` equivalents across docs, prompts, and tooling.

| Deprecated Legacy Concept | Canonical `v5.5.0` Replacement | Reason & Migration Guidance |
|---------------------------|--------------------------------|-----------------------------|
| **Sub-agent** *(when referring to an `agents/*.md` role file)* | **Agent** *(for role spec)* / **Shard Instance (`role#shard`)** *(for TIER 1 runtime process)* | Conflates static specialist definitions (`agents/*.md`) with runtime TIER 1 sub-agent processes (`invoke_subagent`). |
| **Matrix Skill Discovery** *(as a standalone system name)* | **HSOL (`HSOL v5.5`)** + **`skill-seeker`** | Misses the 2-tier vault split (`skills/` vs `skills_library/`), `compact-index.json` `O(1)` lookup, and dynamic `_dynamic.yaml` governance. |
| **Legacy Skill Finder Crawler** *(early single-tier skill search)* | **`skill-seeker` (`skills/skill-seeker/SKILL.md`)** + **`npx skills find`** | Replaced by 2-Step `O(1)` resolution over `matrix-skills/compact-index.json` (`1,462` local skills) with external CLI fallback only on `:hard` / `:team` `< 0.8`. |
| **`:focus` Variant** | **`:fast` / `:hard` / `:team`** (`defaultVariant = auto`) | Consolidated into the deterministic 3-tier depth model plus command-specific variants (`:core\|:business\|:audit`, `:init\|:run\|:audit`, `:council\|:pipeline`). |
| **Nested Command Subdirectories** *(per-command variant folders)* | **Flat Command Layout (`commands/{cmd}-{variant}.md`)** | Flattened to `87` `commands/*.md` files + `6` `commands/_ref/*.md` (`93` total) for cross-platform slash-command compatibility across all `5` AI tools. |
| **Mandatory Turn-1 Multi-Rule Pre-Flight** *(eagerly reading multiple `rules/*.md` on Turn 1)* | **Zero-Latency Entrypoint + On-Demand Mode B Rule Loading** | Compact `<= 250`-line root entrypoints embed the Smart-Hybrid gate and 5-Field Handoff Packet so Turn 1 dispatches immediately. |
| **Rigid Single-Executor Team Cap** *(forcing 1 executor on large multi-file scopes)* | **Elastic Golden Diamond (`1 Tech Lead + 1..6 role#shard Executors + 1..3 Critics`)** | Horizontally shards executors (`<= 3–4 OWNED_FILES` each) while preserving the 3 adversarial governance pillars. |
| **Legacy `E1–E4` / `A1–A10` Ranges** | **`E0–E6` Error Classification** & **`A1–A14` Anti-Pattern Registry** | Expanded in `v5.5.0` to cover `E0` Warm Auto-Revive, `E5` CLI Gate Auto-Repair, `E6` Cross-Engine Escalation, and `A11–A14` swarm/fast-forward laws. |

## Commonly Confused Terms

### `Mode A` vs. `Mode B`

| Dimension | `Mode A` (Micro Direct — Tier 0) | `Mode B` (Multi-Agent Orchestration — Tiers 1–3) |
|-----------|----------------------------------|--------------------------------------------------|
| **Trigger** | `<= 2` already-known files, `1` domain, `0` exploration, no `/cmd`, no NL workflow intent | Unknown files, `> 2` files, `>= 2` domains, explicit `/cmd`, or `17`-language workflow intent |
| **Sub-agents** | `0` (primary agent executes directly) | `2–10+` parallel `role#shard` sub-agents (`<= 3–4 OWNED_FILES` each) |
| **Quality Gates** | Pragmatic 2-Tier Coding Standards + Persistent Verification | Full 5-Field Handoff Packets + deterministic `boomopen` CLI gates |

### Core Skill (`skills/`) vs. Library Skill (`skills_library/`) vs. Dynamic Skill (`_dynamic.yaml`)

| Dimension | Core Skill (`22`) | Library Skill (`1,440`) | Dynamic Skill (`0+`) |
|-----------|-------------------|-------------------------|----------------------|
| **Disk Path** | `{SKILLS_PATH}/<id>/SKILL.md` | `{LIBRARY_PATH}/<id>/SKILL.md` | `{SKILLS_PATH}/<id>/SKILL.md` |
| **Idle Context Cost** | Listed in `<skills>` (`0ms`) | `0` idle tokens (dormant) | Tracked in `matrix-skills/_dynamic.yaml` |
| **Lookup Path** | Step 1 (`<skills>`) | Step 2 (`compact-index.json` via `skill-seeker`) | `_dynamic.yaml` + `npx skills find` |
| **Trust Level** | `1.0` (curated) | `1.0` (curated) | `0.3 -> 0.5 -> 0.7 -> 1.0` |

### Command vs. Variant vs. Phase / Wave

| Dimension | Command | Variant | Phase / Wave |
|-----------|---------|---------|--------------|
| **Granularity** | Workflow intent family (`36` base) | Execution depth & topology (`87` flat files) | Ordered stage or parallel shard batch |
| **Example** | `/cook` | `/cook:team` (`commands/cook-team.md`) | `Wave 2: Parallel Feature Shards` |
| **File Location** | `commands/cook.md` | `commands/cook-team.md` | Section inside `commands/cook-team.md` + `PLAN-{scope}.md` |

### Handoff (`handoffs`) vs. 5-Field Handoff Packet vs. Stateful Handoff (`L8`)

| Dimension | Handoff (`handoffs` field) | 5-Field Handoff Packet | Stateful Handoff (`L8`) |
|-----------|----------------------------|------------------------|-------------------------|
| **Artifact** | `agents/{name}.md` frontmatter array | Sub-agent prompt brief (`boomopen cook packets`) | Constitutional Law in `rules/CORE.md` |
| **Purpose** | Declares allowed specialist transitions | Locks Mission, `SHARED_CONTRACT`, `OWNED_FILES`, `READ_ONLY_FILES`, Verification | Freezes validated upstream deliverables (`RESEARCH`, `DESIGN`, `PLAN`) as immutable constraints |
