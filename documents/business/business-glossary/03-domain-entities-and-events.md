## Entity Vocabulary (`14` Core Entities)

### 1. Agent & Shard Instance (`role#shard`)

| Attribute | Type | Description |
|-----------|------|-------------|
| `name` | string | Specialist identifier (`22` files in `agents/{name}.md`) |
| `description` | string | Concise mission summary in YAML frontmatter |
| `profile` | string | `{domain}:{category}` inheritance key mapped in `matrix-skills/_index.yaml` |
| `handoffs` | string[] | Permitted downstream specialist transitions |
| `category` | enum | `meta \| execution \| validation \| research \| support` |
| `shard_key` | string | Runtime scoped key (`<role>#<shard>`, e.g. `backend-engineer#auth`) |
| `conversation_id` | string | Warm session handle stored in the Active Sub-agent Session Registry |
| `owned_files` | string[] | Disjoint write lock (`<= 3–4` heavy files or `1` vector note `*-v{k}.md`) |

| Lifecycle State | Description |
|-----------------|-------------|
| **Defined** | Specialist `.md` spec (`<= 450` lines) exists in `agents/` |
| **Spawned (Warm)** | Launched via `TIER 1` (`TypeName: "self"`, `Model: "inherit"`) with a 5-Field Handoff Packet; `role#shard -> conversationId` recorded |
| **Active / Reused** | Executing wave work or resumed across Round 2/3 debates and `E2`/`E5` fixes via `send_message` |
| **Verified** | Passed `boomopen` CLI gates (`research\|design\|plan\|cook\|reconcile\|audit\|check`) and returned deliverables |

### 2. Team (`Elastic Golden Diamond`)

| Attribute | Type | Description |
|-----------|------|-------------|
| `team_dir` | string | One of `18` `*-team` folders under `agents/teams/` (`54` role files + `18` `_team.md` = `72` files) |
| `lead_pillar` | Agent | Single `[1]` Tech Lead / Lead Researcher / Lead Debugger / Lead Planner |
| `executor_pillar` | Agent[] | `[1..6]` parallel `role#shard` executors holding disjoint `OWNED_FILES` |
| `critic_pillar` | Agent[] | `[1..3]` parallel critics/testers (`reviewer`, `security-engineer`, `tester`) |
| `topology` | enum | `Topology A` (Turn-1 Parallel Fan-Out) or `Topology B` (Contract-Lock First) |
| `mailbox` | file | Append-only Brain Artifact `MAILBOX-{date}.md` (`C8-TEAMS-01`) |

| Lifecycle State | Description |
|-----------------|-------------|
| **Defined** | Team directory exists in `agents/teams/*-team/` (`<= 450` lines per file) |
| **Fanned Out** | Pillars spawned in parallel (`1-1-1` up to `1 + 6 + 3`) |
| **Debating** | Targeted shards exchanging evidence in `MAILBOX-{date}.md` via warm `send_message` (max `3` rounds, `C8-TEAMS-02`) |
| **Consensus** | Deterministic CLI gate exit `0` + 3-pillar Consensus Stamp (`C8-TEAMS-03`) |

### 5. Phase / Wave & 5-Field Handoff Packet

| Attribute | Type | Description |
|-----------|------|-------------|
| `wave_index` | int | Stage or wave index (`Wave 1` Contracts/Tokens -> `Wave 2` Shards -> `Wave 3` QA/Audit) |
| `packet` | object | `MISSION`, `SHARED_CONTRACT`, `OWNED_FILES` (`<= 3–4`), `READ_ONLY_FILES`, `VERIFICATION` |
| `deliverable` | file | Cohesive Brain Artifact (`<= 500` lines) or verified code/test changeset |

| Lifecycle State | Description |
|-----------------|-------------|
| **Compiled** | Emitted deterministically by `boomopen cook packets "<plan.md>" --wave <W>` |
| **Executing** | Parallel shards modifying disjoint `OWNED_FILES` |
| **Gate-Verified** | Verified via `boomopen cook verify-wave` + `boomopen check --strict-phase --no-stubs` and frozen (`L8`) |
| **Auto-Repairing** | On `E2`/`E5` failure, diagnostics routed back to warm `role#shard` via `send_message` |

## Event Vocabulary (`15` Lifecycle Events)

| Event | Trigger | Source -> Target | Deterministic Outcome & Side Effects |
|-------|---------|------------------|--------------------------------------|
| **`install`** | `node cli/install.js install <tool\|--all> [--with-hooks] [--as-plugin]` | CLI -> Platform Bundle, Manifest | Provisions entrypoints, `22` agents, `18` teams, `93` command files, `22` `skills/`, deduplicated `~/.agents/skills_library/` (`1,440` skills), `compact-index.json`, and writes SHA-256 `~/.boomopen/manifests/<tool>.json` |
| **`uninstall`** | `node cli/install.js uninstall <tool\|--all>` | CLI -> Platform Bundle, Manifest | Removes unchanged kit-owned files while preserving user-created and user-modified files |
| **`settings sync`** | `/settings` or `boomopen settings <set\|preset\|mode\|sync\|--ui>` | CLI / UI -> Settings & Entrypoints | Updates `~/.boomopen/settings.json` / `./.boomopen.json` and syncs `BOOMOPEN-SETTINGS` markers in `< 10ms` |
| **`doctor audit`** | `boomopen doctor [--rebuild-index] [--source-only]` | CLI -> Vault, Markdown, Platforms | Rebuilds/verifies `compact-index.json` (`1,462` skills), line budgets, mojibake, manifests, and Conductor engines |
| **`intent / command trigger`** | Explicit `/cmd` or `17`-language NL workflow intent | User -> Entrypoint & Router | Routes into `commands/{cmd}-{variant}.md` (`Mode B`) or executes `Mode A` (`<= 2` known files) |
| **`shard delegation`** | Turn-1 fan-out or wave dispatch (`boomopen cook packets`) | Orchestrator -> `role#shard` | Spawns `TypeName: "self"` (`Model: "inherit"`) with 5-Field Handoff Packet and records `conversationId` |
| **`warm session reuse`** | Follow-up wave, Round 2/3 debate, or `E0`/`E2`/`E5` repair | Orchestrator -> `role#shard` | Resumes exact warm sub-agent via `send_message(Recipient: conversationId)` with `0s` cold-start |
| **`2-step skill resolution`** | Complex task or Handoff Packet assembly | `HSOL v5.5` (`skill-seeker`) -> Curated Skill | Checks `<skills>` (`22` Core) -> queries `compact-index.json` (`1,462`) -> loads `1–3` `SKILL.md` files |
| **`external skill discovery`** | `:hard` / `:team` with local fitness `< 0.8` | `HSOL v5.5` -> Dynamic Skill | Runs `npx skills find` (async for `0.75–0.8`; blocking + confirm for `< 0.75`) |
| **`trust & promotion update`** | Verified dynamic skill execution | `HSOL v5.5` -> `_dynamic.yaml` / `compact-index.json` | Advances trust (`0.3 -> 0.5 -> 0.7 -> 1.0`) and auto-promotes at `>= 10` runs & `>= 85%` success |
| **`cli gate verify`** | Artifact or wave completion | CLI -> Artifact / Codebase / Ledger | Runs `boomopen <research\|design\|plan\|cook\|reconcile\|audit\|check\|ledger>` gates (`exit 0` required before advancing) |
| **`phase / wave complete`** | All shard deliverables + CLI gates pass | Phase -> Next Wave / Ledger | Freezes deliverable under `Stateful Handoff (L8)` and advances DAG / `.boomopen/project-ledger.json` |
| **`consensus reached`** | All `3` Golden Diamond pillars sign off + CLI gate `0` | Team -> Consensus Stamp | Appends final stamp in `MAILBOX-{date}.md` and releases `:team` deliverable |
| **`council synthesis`** | `boomopen conduct council --task <type>` | Conductor -> Conductor Run | Executes parallel CLI engines and reconciles `<runId>-COUNCIL-SYNTHESIS.md` |
| **`error classified & recovered`** | Runtime interruption, build error, or gate failure | `rules/ERRORS.md` -> `role#shard` / Conductor | Classifies `E0–E6` (`E0` revive, `E2`/`E5` warm fix, `E6` cross-engine dispatch) until verified `exit 0` |
