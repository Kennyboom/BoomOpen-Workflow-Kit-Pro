## Deterministic CLI Suite Mapping (`All 12 boomopen Subcommands`)

Binary entry in `package.json`: `"bin": { "boomopen": "./cli/install.js" }` (run via `node cli/install.js <cmd>` or `boomopen <cmd>` after `npm link`).

| Subcommand | Operations & Flags | Technical Purpose |
|------------|--------------------|-------------------|
| **`install`** | `install <cursor\|copilot\|antigravity\|claude\|codex\|--all> [--with-hooks]` | SHA-256 manifest-backed installation (`~/.boomopen/manifests/<tool>.json`) & user backups |
| **`uninstall`** | `uninstall <tool\|--all>` | Safe removal of unchanged kit-owned files while preserving user creations/edits |
| **`list`** | `list` | Inspect supported platforms, installed versions, and tracked file counts |
| **`settings`** *(alias `config`)* | `settings [status\|get\|set\|mode\|preset\|sync\|reset\|ui\|--ui]` | Manage `~/.boomopen/settings.json`, `./.boomopen.json`, or launch Web UI (`http://127.0.0.1:4567`) |
| **`doctor`** | `doctor [--platform <name>] [--source-only] [--rebuild-index]` | Audit kit source, 5 platform layouts, Markdown budgets/mojibake, `compact-index.json`, and Conductor CLIs |
| **`check`** | `check [dir] [--strict-phase] [--no-stubs] [--ignore <glob>]` | Enforce Pragmatic 2-Tier Coding Standards (`400`/`500` lines, `0` `any`, `0` prod `console.log`, `0` stubs/skips) |
| **`research`** | `research <validate\|brief> <file.md> [--mode research\|brainstorm] [--out <path>] [--json]` | Enforce `RES-G1..G4` citations/options gates and extract `HANDOFF_BRIEF` |
| **`design`** | `design <validate\|contract> <design.md> [--out <path>] [--json]` | Enforce `DESIGN-G1..G4` (OKLCH tokens, 5-State UI Matrix, WCAG 2.2 AA) & extract `DESIGN_CONTRACT` |
| **`plan`** | `plan <validate\|compile> <plan.md> [--sync-ledger]` | Enforce `PLAN-G1..G5` (`OWNED_FILES <= 4` files/shard, DAG acyclicity, `SHARED_CONTRACT`) & sync ledger |
| **`cook`** | `cook <state\|packets\|verify-wave\|preflight> <plan.md>` | Detect prior artifacts, emit 5-Field Wave Packets, and verify `COOK-G1..G4` ownership/anti-stub locks |
| **`ledger`** | `ledger <init\|from-plan\|validate\|status\|next\|verify\|audit>` | Manage `.boomopen/project-ledger.json` with SHA-256 Spec-Hash Drift Guard for `/autopilot` |
| **`conduct`** *(alias `conductor`)* | `conduct <probe\|dispatch\|council\|status>` | Orchestrate cross-engine `Author != Critic` pipelines & 6-task Multi-Engine Councils |

*(External community skill discovery uses `npx skills find [query]` and `npx skills add <owner/repo@skill> -g -y` when triggered by `HSOL v5.5` on `:hard` / `:team`.)*
