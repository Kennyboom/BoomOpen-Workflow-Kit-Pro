### BF-001 — Source-Repository Global Installation & Ownership Ledgers

**Description**: Source-only CLI installer deploys framework assets globally across all 5 AI platforms with SHA-256 ownership ledgers, automatic user backups, and non-destructive marked blocks (`npmPublish: false`).

**Description**: Multi-phase roadmap execution governed by `.boomopen/project-ledger.json` with SHA-256 Spec-Hash Drift Guard and automated Git checkpoint rollback across sessions.

| # | Given | When | Then |
|---|-------|------|------|
| AC-1 | Multi-phase PRD/spec or validated `PLAN-*` is provided | User runs `/autopilot:init` or `boomopen ledger from-plan <plan.md>` | Compiles DAG phases, tasks, and SHA-256 spec hashes into `.boomopen/project-ledger.json` and `.boomopen/ROADMAP-PROGRESS.md` |
| AC-2 | Subsequent session runs `/autopilot:run`, `/autopilot:audit`, or `boomopen ledger rollback` | `boomopen ledger next`, `verify`, or `rollback` executes | Detects spec drift via SHA-256 hash, executes the next unblocked phase (or restores the verified Git checkpoint), and blocks advancement if any stub or unverified task remains |

- **Technical Surface**: `cli/ledger.js`, `commands/autopilot.md`, `commands/autopilot-init.md`, `commands/autopilot-run.md`, `commands/autopilot-audit.md`
- **Dependencies**: `BF-005`, `BF-025`

### BF-027 — Cross-Engine Autonomous Conductor & Multi-Engine Council (`/conduct`)

**Description**: Orchestrates multiple AI CLI engines in `Author != Critic` pipelines and 6-task parallel consensus councils (`research|brainstorm|plan|design|review|debug`).

| # | Given | When | Then |
|---|-------|------|------|
| AC-1 | User runs `/conduct:council` or `boomopen conduct council --task <type>` | Parallel CLI engines execute | Collects `.boomopen/conductor/runs/<runId>-<engine>.md` outputs and synthesizes a 4-part `COUNCIL-SYNTHESIS.md` report |
| AC-2 | `boomopen conduct dispatch` runs a cross-family review or debug step | `Author != Critic` and `READ_ONLY_FILES` guards run | Selects a distinct model family from `--author-engine` and verifies SHA-256 snapshots on `READ_ONLY_FILES` |

- **Technical Surface**: `cli/conductor.js`, `cli/conductor-engines.js`, `commands/conduct.md`, `commands/conduct-council.md`, `commands/conduct-pipeline.md`
- **Dependencies**: `BF-002`, `BF-011`, `BF-025`
