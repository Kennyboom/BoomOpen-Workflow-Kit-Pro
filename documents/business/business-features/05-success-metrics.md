## Validation Status Legend

| Status | Meaning |

### Continuous Verification & Next Measurement Priorities

1. **Automated CI Baseline (Active in `v5.5.0`)**: Every push and pull request runs `npm test` (`34` `node:test` suites), `npm run lint`, `boomopen check .`, `boomopen doctor`, Python syntax compilation, and `npm run test:pack` across Linux, Windows, and macOS on Node `18`, `20`, and `22`.
2. **Controlled A/B Productivity Benchmark**: Run standardized full-stack tasks comparing unassisted prompting vs. `Mode B` `/cook:hard` and `/cook:team` to independently validate time-to-delivery, defect escape rate, and token consumption (`GAP-F01`).
3. **17-Language Intent Evaluation Corpus**: Build a labeled multilingual prompt suite (`17` languages × `14` workflow intents) to measure empirical routing precision and recall (`BF-017`).
