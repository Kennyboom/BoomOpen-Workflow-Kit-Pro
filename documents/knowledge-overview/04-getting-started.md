## Installation (Source-Only Repository Install)

`@boomopen/workflow-kit` `v5.5.0` is distributed **exclusively from source** (`https://github.com/Kennyboom/BoomOpen-Workflow-Kit-Pro`; `.releaserc.json` sets `"npmPublish": false` so nothing is published to npm). Zero `npm install` step is required to install or use the kit because the CLI uses pure Node.js built-ins.

### Step 1: Clone & Install for Your AI Platform(s)

```bash
# 1. Clone the canonical repository
git clone https://github.com/Kennyboom/BoomOpen-Workflow-Kit-Pro.git
cd BoomOpen-Workflow-Kit-Pro

# 2. Install for one platform or all 5 platforms at once
npm run install:antigravity   # Google Antigravity 2.0 (Gemini)
npm run install:claude        # Anthropic Claude Code (add -- --with-hooks for PreToolUse guard)
npm run install:codex         # OpenAI Codex CLI
npm run install:cursor        # Cursor AI Editor
npm run install:copilot       # GitHub Copilot (VS Code)
npm run install:all           # Install across all 5 platforms

# Equivalent direct Node invocation (supports --with-hooks):
node cli/install.js install claude --with-hooks
node cli/install.js install --all
```

### Step 2 (Optional): Link `boomopen` onto Your Global `PATH`

```bash
# Inside BoomOpen-Workflow-Kit-Pro/ (links local checkout; downloads nothing from npm)
npm link

# Now run `boomopen` from any directory:
boomopen list
boomopen doctor
boomopen settings
```

| Platform | Global Entrypoint(s) & Platform Integration | Framework Directory | Core Skills (`22`) & Library Vault (`1,440`) |

## First Run — Slash Commands & Natural-Language Workflows

Open any project in your AI coding tool. You can invoke workflows explicitly via **33 base slash commands** or speak naturally in any of the **17 supported languages**:

```text

# Contract-first plan & 6-Block UI design spec
/plan:hard "add multi-tenant RBAC permissions"

# Root-cause SPIE v3.0 debugging, multi-file bug fix, & adversarial review
/debug:hard "race condition in webhook retry worker"
/fix:hard "resolve duplicate invoice webhook processing"
/review:team "security and concurrency audit of src/payments/"

/autopilot:init "ingest docs/specs/ into .boomopen/project-ledger.json"

# Technical & business documentation generation
/docs:core
/docs:business
```

### Overnight Large Multi-Phase Project Guide (`/autopilot` vs. `/goal` + `/autopilot` + `/audit`)

| Workflow | Best Scope | Context Window Behavior | Quality & Spec Guarantees |
|:---------|:-----------|:------------------------|:--------------------------|
| **`/autopilot` alone** | Single-session or small/medium builds (`< 70%` context) | Runs inside one conversation session; stops cleanly near `~70%` context for manual resume | Initializes `.boomopen/project-ledger.json`, enforces 5 verification gates & Wave 2.5 reconciliation |
| **`/goal` + `/autopilot` + `/audit`** | Large multi-phase projects with `docs/` (overnight autonomous runs) | **`/goal`** acts as the persistent outer runner across phases and auto-resets/continues when context hits `~70%` | **`/autopilot`** enforces ledger state, 5 verification gates & Wave 2.5 spec-reconciliation per phase, then runs Round 1 of **`/audit`** at 100% completion and stops for review |

**Ready-to-copy overnight prompt:**

```text
/goal Use /autopilot to read all project documentation in docs/, initialize project-ledger.json, and autonomously implement every phase sequentially from start to finish (skip the initial PLAN approval pause; every phase must pass all 5 verification gates and reconcile 100% against the specs). After 100% of phases are complete, run Round 1 of /audit and stop with a report for my review.
```

```bash
# 1. Fork https://github.com/Kennyboom/BoomOpen-Workflow-Kit-Pro on GitHub, then clone:
```

### Conventional Commits & Release Rules (`.releaserc.json`)

| Prefix | Purpose | SemVer Impact (`5.5.0` Baseline) |
|--------|---------|----------------------------------|
| `feat:` | New capability or command | Minor (`5.x.0`) |
| `fix:`, `perf:`, `refactor:` | Bug fix, performance tuning, or refactoring | Patch (`5.5.x`) |

## Common Issues and Troubleshooting

### `"command not found: boomopen"`

**Cause**: Either `npm link` has not been run yet, or npm's global bin directory is not on your shell `PATH`.

```bash
# Run directly from your BoomOpen-Workflow-Kit-Pro clone without global linking:
node cli/install.js doctor

# Or link globally and ensure npm's global bin is in PATH:
npm link
export PATH="$(npm config get prefix)/bin:$PATH"
```

### `"Node.js version too old"`

**Cause**: BoomOpen Workflow Kit requires Node.js `>=18.0.0` (`20` or `22` LTS recommended, and required if building `web/` with Vite 7).

```bash
node --version
nvm install 22 && nvm use 22
```

### `"Commands or rules not picked up by AI tool"`

**Cause**: The IDE or CLI session started before installation, or an entrypoint file is missing.

```bash
# Run doctor to inspect every installed platform's entry files, framework dir, and skills vault:
node cli/install.js doctor

# Verify platform entrypoints directly:
ls ~/.gemini/GEMINI.md                        # Antigravity (Gemini)
ls ~/.claude/CLAUDE.md                        # Claude Code
ls ~/.codex/CODEX.md ~/.codex/config.toml     # OpenAI Codex
ls ~/.cursor/CURSOR.md ~/.cursor/rules/       # Cursor
ls ~/.copilot/COPILOT.md                      # GitHub Copilot

# Re-install for your platform and restart/reload the editor window:
node cli/install.js install <antigravity|claude|codex|cursor|copilot>
```
