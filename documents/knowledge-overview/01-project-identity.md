## Purpose

BoomOpen Workflow Kit (`v5.5.0`) transforms a single AI coding assistant into an orchestrated engineering organization of **22 specialist agents** (including `spec-reconciler`), **18 Elastic Golden Diamond teams**, **36 base slash commands (`93` command files)**, **5 core execution presets** (`frontier-guardrails` default with `carbon-guardrails` alias, `smart-hybrid`, `solo-fast`, `deep-architect`, `adversarial-team`), and **`1,462` indexed skills** (`22` Core Skills + `1,440` On-Demand Library Skills). It pairs low-latency Slim Guardrails & Mode A execution on daily tasks with parallel contract-locked multi-agent sharding and deterministic CLI verification gates on complex engineering work (**Mode B**) across all **5 supported AI coding platforms**.

---

## Problem Statement

AI coding assistants (Antigravity, Claude Code, OpenAI Codex, Cursor, GitHub Copilot) are capable generalists out of the box, yet unstructured usage across real production repositories breaks down in predictable ways:

- **Context bloat & solo crawling** — A single agent sequentially reads dozens of files, polluting its context window before writing code.
- **Inconsistent quality & hollow output** — Without deterministic gates, assistants leave `TODO` stubs, explicit `any` types, unverified fixes, or skipped regression tests.
- **Parallel write collisions** — Multi-agent runs overwrite shared files or drift on API/schema shapes when no contract or file lock exists.
- **Repeated per-project setup & platform lock-in** — Custom prompts built for one repository or IDE fail to carry over to other projects or AI coding tools.
- **Single-model blind spots** — When one model family deadlocks on a subtle root-cause bug or architectural tradeoff, there is no built-in way to arbitrate across engines.

## Solution

BoomOpen Workflow Kit `v5.5.0` resolves these challenges through six integrated layers:

1. **Non-destructive 5-platform global installation** — Installs once into Antigravity (`~/.gemini/`), Claude Code (`~/.claude/`), OpenAI Codex (`~/.codex/`), Cursor (`~/.cursor/`), and GitHub Copilot (`~/.copilot/`), tracked by SHA-256 ownership manifests (`~/.boomopen/manifests/<tool>.json`) and automatic backups (`~/.boomopen/backups/`).
2. **Smart-Hybrid Mode A / Mode B Gate & 17-Language Routing** — Known-target micro-edits (`<= 2` files, `1` domain) execute directly in Mode A with zero orchestration tax; unscoped exploration, `> 2` files, `>= 2` domains, natural-language workflow requests across **17 languages**, or explicit `/cmd` workflows trigger Mode B with **4-Tier Dynamic Elastic Swarm Sharding (`role#shard`, `<= 3-4 OWNED_FILES` per shard)** and **Scoped Warm Sub-agent Reuse (`send_message`)**.
3. **22 specialist agents & 18 Elastic Golden Diamond teams** — Dedicated domain specialists (`backend-engineer`, `frontend-engineer`, `database-architect`, `researcher`, `debugger`, `spec-reconciler`, `security-engineer`, `tester`, `reviewer`, etc.) and adversarial teams scaling from `1-1-1` (`3` agents) up to `1 Tech Lead + 1..6 Parallel Shard Executors + 1..3 Parallel Critics`.
4. **36 base slash commands (`93` flat command files)** — `87` flat workflow files in `commands/*.md` plus `6` shared protocols in `commands/_ref/*.md`, spanning `/cook`, `/code`, `/plan`, `/design`, `/research`, `/brainstorm`, `/debug`, `/fix`, `/test`, `/review`, `/audit`, `/report`, `/docs`, `/deploy`, `/autopilot`, `/conduct`, `/pr`, `/onboard`, `/release`, `/ask`, `/settings`, `/orchestrate`, `/save`, `/recap`, and specialized utilities.
5. **2-Step `O(1)` Skills Vault (`HSOL v5.5`)** — `22` pre-loaded Core Skills (`skills/`) plus `1,440` dormant Library Skills (`skills_library/`, deduplicated across IDEs via `~/.agents/skills_library`) indexed in `matrix-skills/compact-index.json` (`1,462` total skills across `19` domains), resolved on demand via `skill-seeker` with zero idle prompt overhead.
6. **14 deterministic `boomopen` CLI subcommands** — `install`, `uninstall`, `list`, `settings` (5 core presets + CSP-hardened Local Web UI on `http://127.0.0.1:4567`), `doctor`, `check --strict-phase --no-stubs`, `research`, `design`, `plan`, `cook`, `reconcile` (Wave 2.5 spec-to-code wiring scanner), `audit` (multi-round whole-project audit ledger + `rollback`), `ledger` (Multi-Session Autopilot + `rollback`), and `conduct` (Cross-Engine Conductor & 6-Task Multi-Engine Council). For large overnight multi-phase runs, pair `/goal` + `/autopilot` + `/audit` to drive all phases through 5 gates + Wave 2.5 reconciliation and stop at Round 1 `/audit` for review.

## First 60 Minutes — Onboarding Checklist

This checklist takes a new user or contributor from zero to productive with BoomOpen Workflow Kit `v5.5.0` in one hour.

### Minutes 0–10: Environment Setup

- [ ] Verify Node.js `>=18.0.0` is installed: `node --version`
- [ ] Verify npm is available: `npm --version`
- [ ] Verify git is available: `git --version`
- [ ] Ensure at least one supported AI platform is installed (Antigravity, Claude Code, OpenAI Codex, Cursor, or VS Code + GitHub Copilot)

### Minutes 10–20: Clone, Install, and Verify

- [ ] Clone the repository: `git clone https://github.com/Kennyboom/BoomOpen-Workflow-Kit-Pro.git && cd BoomOpen-Workflow-Kit-Pro`
- [ ] Install for your AI platform(s): `node cli/install.js install --all` (or `npm run install:antigravity`, `npm run install:claude`, `npm run install:codex`, `npm run install:cursor`, `npm run install:copilot`)
- [ ] Optionally link `boomopen` onto your global `PATH`: `npm link`
- [ ] Run the health audit: `npm run doctor` (or `boomopen doctor`) to verify source bundles, `1,462` indexed skills, and installed platform layouts
- [ ] Inspect or customize the 5 core presets (`frontier-guardrails` default, `carbon-guardrails` alias, `smart-hybrid`, `solo-fast`, `deep-architect`, `adversarial-team`): `npm run settings` or launch the Web Control Center via `npm run settings:ui` (`http://127.0.0.1:4567`)

### Minutes 20–30: Read Core Concepts

- [ ] Read [../../README.md](../../README.md) — understand Mode A vs. Mode B, the 6 Core Pillars of `v5.5`, and platform support
- [ ] Read [../../rules/CORE.md](../../rules/CORE.md) — understand the 4-Tier Elastic Swarm, 17-Language Routing, and 10 Laws (`L1-L10`)
- [ ] Browse [../../agents/](../../agents/) and [../../agents/teams/](../../agents/teams/) — inspect specialist profiles (`backend-engineer.md`, `researcher.md`) and Golden Diamond teams (`fullstack-team/_team.md`)

### Minutes 30–40: Run Your First Workflows

- [ ] Open a project in your AI coding assistant (commands work via `/cmd` or natural language in 17 languages)
- [ ] Try a fast build: `/cook:fast "add a health check endpoint"`
- [ ] Try deep research: `/research:team "compare Hono RPC vs tRPC for edge APIs"`
- [ ] Try contract-first planning: `/plan:hard "build passkey authentication"`
- [ ] Approve the plan (click **Proceed** on Antigravity or say `"proceed"` / `/code:hard`) to watch Direct Plan-to-Executor Dispatch in action

### Minutes 40–50: Explore Skills & Deterministic Compilers

- [ ] Browse [../../commands/](../../commands/) — inspect flat routers (`commands/cook.md`, `commands/cook-hard.md`) and shared protocols (`commands/_ref/`)
- [ ] Inspect [../../matrix-skills/compact-index.json](../../matrix-skills/compact-index.json) and [../../skills/skill-seeker/SKILL.md](../../skills/skill-seeker/SKILL.md) to see how `1,462` skills (`22` in `skills/` + `1,440` in `skills_library/`) resolve in `O(1)`
- [ ] Run `boomopen check . --strict-phase --no-stubs` on a codebase to test Pragmatic 2-Tier Coding Standards enforcement

### Minutes 50–60: Documentation, Autopilot, and Multi-Engine Council

- [ ] Run `/docs:core` in a project to generate `./documents/` technical knowledge packs
- [ ] Explore `/autopilot:init` (`boomopen ledger`) for multi-session spec-to-code roadmaps, or run `/goal` + `/autopilot` + `/audit` for unattended overnight multi-phase builds (see [04-getting-started.md](./04-getting-started.md))
- [ ] Run `boomopen conduct probe` to detect installed CLI engines for `/conduct:council`
