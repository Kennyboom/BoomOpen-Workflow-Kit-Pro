> ⛔ **ALL `/design` workflows produce DESIGN SPECIFICATIONS & PROTOTYPE ARTIFACTS ONLY. NO APPLICATION SOURCE CODE.**
>
> 1. **Cohesive Single-File Rule (`<= 500` lines — NO `{name}/` Folder Split)**:
>    - Always write `<appDataDir>\brain\<conversation-id>\DESIGN-{request}.md` as **1 single, self-contained 6-Block file up to 500 lines** (NEVER split `DESIGN-{request}.md` into a `{name}/` directory at 150 lines, and NEVER split into separate `DESIGN` vs. `DESIGN-SPEC` files!).

>    - Set `RequestFeedback: false` on all supporting/intermediate files (`SCOUT-{request}.md`, `RESEARCH-{request}.md`, `COUNCIL-DESIGN-{request}.md`, `DESIGN-PREVIEW-{request}.html`, and `UserFacing: false, RequestFeedback: false` on `MAILBOX-{date}.md`).

>    - When multi-platform design synthesis is requested (or `engines.designer = "council"`), run `node ~/.{TOOL}/skills/boomopen-workflow-kit/cli/install.js conduct council --task design --prompt "<request>"`.
> 5. **Deterministic 4-Gate CLI Validation & Contract Extraction (`boomopen design`)**:

## 🔀 3-TIER ADAPTIVE ROUTING LOGIC

```
IF design is localized (single component, token tweak, quick mockup <= 2 files):
  → Route to /design:fast (commands/design-fast.md)

IF design is a full feature, multi-screen flow, or new UI system (Default for auto):
  → Route to /design:hard (commands/design-hard.md — 2-Wave Parallel Discovery + 6-Block Spec)

IF design requires maximum quality with adversarial review (or execution.mode = team / council):
  → Route to /design:team (commands/design-team.md — 2-Stage Elastic Golden Diamond)
```

| Route | Scope & Ceremony | Post-Design Continuation |
|-------|------------------|--------------------------|
| `/design:fast` | Tier 1 Rapid Component Spec (`1` fast token scout + 6-Block `DESIGN-{request}.md`) | Click **"Proceed"** → `/code:fast` or `/plan:fast` |
| `/design:hard` | Tier 2 2-Wave Parallel Design (`scouter` + `researcher` `ui-ux-pro-max` → 6-Block Spec + Live Preview) | Click **"Proceed"** → `/plan:hard` or `/code:hard` |
| `/design:team` | Tier 3 2-Stage Elastic Golden Diamond (`agents/teams/design-team/_team.md`) + 4-Gate Adversarial Audit | Click **"Proceed"** → `/plan:team` or `/code:team` |
